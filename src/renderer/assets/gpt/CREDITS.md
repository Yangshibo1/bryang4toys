# GPT 白龙娘素材

本目录的角色立绘来自 [CrossPet](https://github.com/lokicorvus/crosspet) 的 [`characters/gpt`](https://github.com/lokicorvus/crosspet/tree/main/characters/gpt)，原始 GPT「御姐白龙」设定出自 B 站 **ZipZipPipe**；本组立绘由 CrossPet（lokicorvus 及贡献者）基于该设定制作。

取用时的上游提交为 `6e98970f6ff9b44e8ac85215241cabcd78f67d92`（2026-10-23）。

原文件对应：`idle.webp`、`idle-blink.webp`、`thinking.webp`、`happy.webp`、`running.webp`。这些 WebP 文件按原样存放；本项目通过 CSS 展示表情和眨眼，构建时缩放组合为应用图标。未使用第三方的执行代码。
