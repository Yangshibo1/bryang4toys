# 米卡 Mika

住在自己 Mac 上的个人 AI 助手。点击桌面的 GPT 白龙娘，就能聊天、记事、讨论时间安排；米卡可以结合你的个人画像和长期记忆给出建议，也会在到点时提醒你。

所有任务、画像、记忆和设置保存在本机，无需部署后台。当前优先支持一台 Mac，尚未实现多端同步。

## 下载并打开

打开本仓库 **Actions → Build macOS app → 最近一次成功运行 → Artifacts**，按自己的 Mac 下载：

- Apple 芯片：`Mika-macOS-arm64.zip`。
- Intel：`Mika-macOS-x64.zip`。

下载需要登录 GitHub。解压后把 `Mika.app` 拖入“应用程序”并打开。每次推送到 `main` 会重新构建，也可以手动运行工作流；安装包保留 30 天。

工作流在 macOS 上生成个人临时签名，使用 `ditto` 打包和解压，并在打包前后执行 `codesign --verify --deep --strict`。随后启动本机架构的解压应用，检查真实桌面窗口、画像与记忆保存、关闭面板后的定时提醒和重启恢复；全部通过后才上传。两种架构均验签，实际启动测试覆盖构建机的原生架构，另一种架构仍需要对应 Mac 验收。

临时签名用于检查完整性，尚未经过 Apple Developer ID 签名和公证。首次打开可能需要在“系统设置 → 隐私与安全性”选择“仍要打开”。若最新安装包仍提示“已损坏”，保留错误信息以便排查，无需关闭系统检查。

### 从慢慢 Momo 升级

先从菜单栏完全退出旧版 Momo，再打开 Mika。米卡沿用旧应用身份，首次运行会尝试迁移旧版的本地数据，保留已有任务、设置和对话。安装新版 `Mika.app` 后可替换旧版 `Momo.app`；不要手动删除旧数据目录。通过菜单栏的“打开数据文件夹”查看实际使用的位置。原 `MOMO_DATA_DIR`、`MOMO_DEV_URL` 环境变量继续兼容，新配置使用 `MIKA_DATA_DIR`、`MIKA_DEV_URL`。

## 先连接你自己的模型

打开设置，填写接口地址、密钥和模型，选择接口协议，然后使用“测试连接”检查。**只有配置密钥后，聊天才会请求模型**；未配置时可使用本地记事和提醒，但不会获得真正的模型对话能力。

| 配置项 | 填写方式 |
| --- | --- |
| API 地址 | 填服务商提供的基础地址，例如 `https://api.openai.com/v1` 或兼容中转地址；不需要手动追加 `/chat/completions` 或 `/responses` |
| 接口协议 | 按服务商支持选择 **Chat Completions** 或 **Responses** |
| 模型名称 | 默认预填 `gpt-6-luna`；必须是你所用服务商及账号实际支持的模型名称 |
| API 密钥 | 在桌面应用设置里填写自己的 Key |

`gpt-6-luna` 是按个人偏好预填的请求名称，不代表所有服务商都提供它。若连接测试提示模型不存在或协议不支持，按服务商说明修改模型或协议。连接测试会真正向所填接口发送短请求，可能消耗少量额度。测试成功说明当次连接和模型响应正常，不保证后续额度和接口始终可用。

接入后可以直接说：

```text
我今天有点累，但晚上之前要把报告交了，帮我安排一下。
我希望你回答简短一点，先给结论，再给具体步骤。
记住我通常上午比较专注，尽量把重要的事放在上午。
明天下午三点开会，提前半小时提醒我准备材料。
```

模型请求失败会显示原因，任务不会被悄悄按失败请求修改。清空密钥可回到本地模式。

## 让米卡逐渐了解你

在个人画像中填写称呼、身份、背景、目标、偏好、作息，以及希望米卡采用的交流方式。长期记忆用于保存值得跨对话保留的信息，例如工作习惯、长期目标、回答偏好。

你可以查看、添加、修改和删除记忆；连接模型后，米卡也可以从对话中保存或更新相关记忆。它们会保留在本机，关闭应用后再次聊天时仍可使用。

配置模型后，聊天会将当前任务、最近对话和手工填写的画像发送给你选择的接口。长期记忆开启时，还会发送已保存的记忆，并允许按对话更新记忆；关闭后保留已有内容，不再向模型提供长期记忆，也不自动写入对话记忆。手工画像仍用于个性化。API Key 不返回给聊天界面，和其他设置一起存放在本机数据目录。

## 记事与提醒

无需模型也可以先试：

```text
10分钟后提醒我喝水
明天下午三点提醒我开会
记一下写报告，预计30分钟，很重要
今天怎么安排
完成 写报告
把开会推迟10分钟
```

本地模式支持中文明确时间、待办、完成、推迟和基础排程建议。没有具体小时的事项先放入待办，不编造提醒时间；点击任务可编辑。含糊的上午/下午、已过去的日期、多个时间或“事件时间＋提前提醒”等复杂表述会请你明确，或交给已配置的模型处理。“推迟十分钟”统一指从当前时间起十分钟后。

在 macOS 系统设置中允许 Mika 的通知，再用应用里的“测试系统通知”检查。关闭面板后，菜单栏图标和桌宠仍可运行；从菜单栏可重新打开面板、显示宠物或完全退出。完全退出、Mac 关机或睡眠期间不能准时弹窗，下一次启动或唤醒时会补查到期任务；同一次已送达提醒不会重复发送。

## 本地开发与验证

使用 Node.js 24，在项目目录运行：

```bash
npm ci
npm run dev
```

开发命令会构建 Electron 主进程、启动 Vite，并打开桌面面板和宠物。界面支持热更新，主进程修改后重启命令。

```bash
npm run dev:web          # 浏览器本地预览
npm run build            # 类型检查并构建界面与桌面程序
npm test                 # 核心、持久化、画像、记忆与模型协议测试
npm run test:ui          # Chromium 网页交互测试，先 build
npm run test:desktop     # 真实 Electron IPC、提醒、画像记忆 CRUD 和重启测试
npm run package:mac      # 在 Mac 上构建、签名、验签并打包两种架构
npm run test:packaged:mac # 在 Mac 上启动解压后的原生架构应用，先 package:mac
```

仅打包一种架构可设置 `MIKA_ARCH=arm64` 或 `MIKA_ARCH=x64`，旧 `MOMO_ARCH` 仍兼容。Mac 安装包必须在 macOS 上构建；Linux 云开发可使用仓库 Actions 工作流。网页测试可用 `CHROMIUM_PATH` 指定 Chromium，无显示器 Linux 的桌面测试需要 Xvfb。

Electron 从官方发布下载，保留完整性校验。使用网络代理的 Node.js 24 环境可设置 `NODE_USE_ENV_PROXY=1 NODE_USE_SYSTEM_CA=1`；打包下载可设置 `ELECTRON_GET_USE_PROXY=1`。

浏览器预览用于本地页面和记事交互，不保存或使用 AI Key，关闭网页后不会继续检查提醒。日常使用请选择桌面客户端。自动化模型测试使用本地 HTTP 测试服务，不会调用付费 API；真实接口可在你的客户端设置中测试。系统通知权限、桌宠在不同桌面下的外观及非原生架构安装包仍需在对应 Mac 验收。

## 项目结构

```text
src/core       中文时间、记事、排程和到期判断
src/main       Electron 窗口、菜单栏、本地持久化、模型请求、记忆和提醒
src/preload    桌面界面与主进程之间的 API
src/renderer   React 面板、画像与记忆管理、设置和白龙娘立绘
src/shared     类型和浏览器预览适配器
scripts        开发、构建、打包和功能验证
tests          核心与服务测试
```

## 角色素材

GPT 白龙娘采用 [CrossPet](https://github.com/lokicorvus/crosspet) 的透明立绘，原型「御姐白龙」出自 B 站 **ZipZipPipe**。桌宠、聊天头像与应用图标使用同一形象；待机时呼吸与眨眼，AI 请求时切换思考立绘，到点提醒时切换运行立绘。

立绘及由其生成的应用图标采用 **CC BY-NC-SA 4.0**，来源与声明见 [素材署名](src/renderer/assets/gpt/CREDITS.md) 和 [素材许可](src/renderer/assets/gpt/LICENSE.md)，应用包内也保留副本。
